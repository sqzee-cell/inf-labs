# Создание HTML страниц и форматирование текста

**Вариант 6.** Дубограй Артем Юрьевич, группа 615.

**Цель работы:** изучить теги форматирования, структуру HTML-страницы и создание трёхцветного текстового изображения.

**Источник:** папка HTML, «Лабораторная работа. Форматирование. Титульный лист». Задание общее для всех вариантов; изображение выбирается самостоятельно.

## 1 Титульный лист

Создан файл index.html с русским языком документа и кодировкой UTF-8. РГРТУ оформлено заголовком h1, Кафедра ВПМ — h2, название лабораторной — h3. Слова «Выполнил», «Проверил», «Задание» выделены полужирным начертанием strong. Текст задания выделен курсивом em и набран шрифтом Arial. Тема лабораторной выделена цветом.

Титульный блок содержит имя студента, группу 615, проверяющего Никичкина Б. В. и год 2026. Номер 7 соответствует порядку темы в графике, а не номеру варианта.

## 2 Трёхцветное изображение

Текстовый рисунок «Старт» изображает ракету. Использован моноширинный шрифт Consolas с запасным Courier New. Элемент pre сохраняет пробелы и переводы строк, а span задаёт три цвета: синий #174e85, золотистый #a15c00, красный #b72f3a.

Рисунок состоит из текстовых символов. Изображения, SVG и canvas для него не используются. На узком экране рисунок доступен с горизонтальной прокруткой, а текст страницы переносится.

## 3 Просмотр и проверка

Для просмотра достаточно открыть index.html в браузере. Установка дополнительных программ и подключение к интернету для страницы не нужны.

Проверены наличие обязательных тегов, три цвета рисунка и отсутствие внешних зависимостей. В браузере проверяется сохранение геометрии текстового рисунка и читаемость титульного листа.

**Вывод:** освоено оформление текста и создание страницы средствами HTML и CSS. Моноширинный шрифт и сохранение пробелов позволяют строить изображения из символов.
