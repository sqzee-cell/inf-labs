## 1.1.1 Перевод из десятичной системы в двоичную

Целую часть делим на 2, остатки читаем снизу вверх. Дробную часть последовательно умножаем на 2 и выписываем целые части произведений. Скобки в записи дроби обозначают период.

91 = 64 + 16 + 8 + 2 + 1 = (1011011)₂.

13,01 = 13 + 1/100 = (1101,00(00001010001111010111))₂.

Первые шаги для дробной части: 0,01·2 = 0,02 → 0; 0,02·2 = 0,04 → 0; 0,04·2 = 0,08 → 0; 0,08·2 = 0,16 → 0; 0,16·2 = 0,32 → 0; 0,32·2 = 0,64 → 0; 0,64·2 = 1,28 → 1; 0,28·2 = 0,56 → 0. Первые восемь битов: 00000010.

При округлении до 12 двоичных знаков: 13,01 ≈ (1101,000000101001)₂ = 13,010009765625. Абсолютная погрешность равна 0,000009765625, что меньше половины единицы последнего десятичного разряда исходного числа: 0,005.

59,3 = 59 + 3/10 = (111011,0(1001))₂.

Дробная часть: 0,3·2 = 0,6 → 0; 0,6·2 = 1,2 → 1; 0,2·2 = 0,4 → 0; 0,4·2 = 0,8 → 0; 0,8·2 = 1,6 → 1. Далее остаток 0,6 повторяется.

При округлении до 8 двоичных знаков: 59,3 ≈ (111011,01001101)₂ = 59,30078125. Погрешность 0,00078125 < 0,05. Дополнительные двоичные разряды сохранены, чтобы перевод не терял исходную десятичную точность.

## 1.1.2 Перевод из двоичной системы в десятичную

Значение позиционной записи равно сумме цифр, умноженных на соответствующие степени основания. После запятой используются отрицательные степени.

(111111)₂ = 32 + 16 + 8 + 4 + 2 + 1 = 63.

(1110000,010110)₂ = 64 + 32 + 16 + 1/4 + 1/16 + 1/32 = 112,34375.

(11000,101110)₂ = 16 + 8 + 1/2 + 1/8 + 1/16 + 1/32 = 24,71875.

## 1.2 Арифметические действия

### 1.2.1 Двоичное выражение

Требуется вычислить (1101)₂/(1010)₂ − (1,01)₂. В десятичной системе это 13/10 − 1,25 = 1,3 − 1,25 = 0,05.

Точное частное: (1101)₂/(1010)₂ = (1,0(1001))₂. Точный результат: (0,00(0011))₂.

Деление по дробным разрядам: остаток 3; 3·2 = 6 < 10 → 0; 6·2 = 12 → 1, остаток 2; 2·2 = 4 → 0; 4·2 = 8 → 0; 8·2 = 16 → 1, остаток 6. Частное до пятой позиции после запятой — (1,01001)₂ при усечении.

(1,01001)₂ − (1,01000)₂ = (0,00001)₂ = 0,03125. Если округлять до пяти позиций, получаем (1,01010)₂ − (1,01000)₂ = (0,00010)₂ = 0,0625. Точный ответ 0,05 лежит между этими приближениями. В условии сказано «до пятой значащей цифры после запятой», но способ округления не задан; здесь показаны оба способа и точное значение.

### 1.2.2 Восьмеричное и шестнадцатеричное выражения

(71,45)₈ − (22,06)₈ = (47,37)₈. При вычитании последних дробных разрядов занимаем единицу: 5 + 8 − 6 = 7; следующий разряд 3 − 0 = 3. В целой части: 1 + 8 − 2 = 7, затем 6 − 2 = 4.

Десятичная проверка: 57,578125 − 18,09375 = 39,484375.

(981,23)₁₆ + (E0,59)₁₆ = (A61,7C)₁₆. Дробная часть: 3 + 9 = C, 2 + 5 = 7. Целая часть: 1 + 0 = 1; 8 + E = 16₁₆, записываем 6 и переносим 1; 9 + 1 = A.

Проверка: 2433,13671875 + 224,34765625 = 2657,484375.

## 1.3.2 Числа с плавающей точкой

Для нормализованных чисел IEEE 754: v = (−1)ˢ·(1 + f/2ᵐ)·2ᴱ, E = e − bias. Здесь s — знак, e — хранимый порядок, f — целое значение поля дроби. Для float: m = 23, bias = 127; для double: m = 52, bias = 1023. Все заданные числа нормализованные.

### Задание 1 Одинарная точность

| Код float | s | e | E | f | Значение |
|---|---|---|---|---|---|
| 45000000 | 0 | 138 | 11 | 0 | 2048 |
| C2F88000 | 1 | 133 | 6 | 7897088 | −124,25 |
| 44FF9000 | 0 | 137 | 10 | 8359936 | 2044,5 |

Например, C2F88000₁₆: знак 1; порядок 10000101₂ = 133; дробь 11110001000000000000000₂. Получаем −(1 + 7897088/8388608)·64 = −124,25.

### Задание 2 Двойная точность

| Код double | s | e | E | Значение |
|---|---|---|---|---|
| 40A0000000000000 | 0 | 1034 | 11 | 2048 |
| C05F900000000000 | 1 | 1029 | 6 | −126,25 |

Поля дроби: 0; 4380454325059584; 4488206464581632 соответственно. Для второго числа: −(1 + 4380454325059584/4503599627370496)·64 = −126,25. Значения float и double во втором столбце исходных вариантов различаются, потому что сами исходные коды задают разные числа.

## 1.3.3 Арифметика в дополнительном коде

Исходные значения: A = 105; B = −46; C = 88; D = 22; E = −55. Требуется X = A + B − C + D − E.

Выбираем 8 бит: все операнды и промежуточные результаты находятся в диапазоне −128…127. Код отрицательного числа получаем инверсией кода модуля и прибавлением единицы.

| Число | Дополнительный код 8 бит | Шестнадцатеричный код |
|---|---|---|
| A = 105 | 01101001 | 69 |
| B = −46 | 11010010 | D2 |
| C = 88 | 01011000 | 58 |
| D = 22 | 00010110 | 16 |
| E = −55 | 11001001 | C9 |
| −C = −88 | 10101000 | A8 |
| −E = 55 | 00110111 | 37 |

Последовательно складываем, отбрасывая перенос за пределы восьми разрядов:

```
01101001 + 11010010 = 00111011   (59)
00111011 + 10101000 = 11100011   (-29)
11100011 + 00010110 = 11111001   (-7)
11111001 + 00110111 = 00110000   (48)
```

Итог: X = (00110000)₂ = (30)₁₆ = 48. Перенос за пределы слова не равен знаковому переполнению; в приведённых шагах знакового переполнения нет.

Десятичная проверка: 105 − 46 − 88 + 22 + 55 = 48.
