# Работа в командной строке с каталогами и файлами

**Вариант 6.** Дубограй Артем Юрьевич, группа 615.

**Цель работы:** освоить создание дерева каталогов, копирование, переименование, объединение и просмотр файлов средствами командной строки Windows.

**Источник:** «Лаб_раб_командная строка.pdf», задание 6, страницы 2–3. В начале методички разрешено использовать отдельный каталог на личном компьютере. Поэтому рабочая область находится в папке этой лабораторной, в подкаталоге work. На учебной виртуальной машине требуемый корневой каталог C: можно выбрать при демонстрации с разрешённым преподавателем путём.

## 1 Требуемое дерево каталогов

```
Name1
|-- Name2
|   |-- Name3
|   `-- Name4
`-- Name5
```

Имена выбраны на латинице, как рекомендует методичка. Каталоги Name3 и Name4 вложены в Name2; Name5 расположен непосредственно в Name1.

## 2 Последовательность действий

Пакетный файл lab_dos.bat выполняет следующие действия:

1. Переходит в собственный каталог и выбирает свободную рабочую область. При первом запуске это work, при следующих — work\run_1, work\run_2 и т. д.

2. Командами MD создаёт дерево каталогов в work.

3. Командой COPY создаёт в Name1 файл Test1.txt из подготовленного текстового файла source.txt. Командой TYPE выводит содержимое на экран.

4. Копирует Test1.txt в каждый из четырёх остальных каталогов.

5. Переименовывает три копии: в Name2 — Test2.txt, в Name3 — Test3.txt, в Name4 — Test4.txt. В Name5 остаётся четвёртая копия Test1.txt: условие требует копию в каждом каталоге, но задаёт только три новых имени.

6. Командой COPY /B объединяет содержимое исходного Test1.txt и копии Test2.txt в Name1\Test5.txt, затем выводит его командой TYPE.

7. Выводит содержимое Name1 командой DIR и дерево рабочей области командой TREE /F /A. Ключ /F добавляет файлы, /A использует символы ASCII для линий.

## 3 Запуск

Открыть папку лабораторной в командной строке и выполнить:

```
lab_dos.bat
```

Файл не удаляет предыдущие результаты. Повторный запуск автоматически создаёт новую рабочую область с очередным номером, поэтому демонстрацию можно повторять без удаления файлов и ручной подготовки.

## 4 Проверка результата

В результирующем дереве пять каталогов. Содержимое Test1.txt, Test2.txt, Test3.txt, Test4.txt и копии в Name5 одинаково. Файл Test5.txt содержит две последовательные копии исходного текста; его размер в байтах вдвое больше исходного.

Успешное выполнение сопровождается сообщением Completed successfully и кодом возврата 0. Сохранённый журнал фактического запуска находится в файле Запуск.txt.

**Вывод:** создано требуемое дерево каталогов и выполнены операции COPY, TYPE, REN, DIR и TREE. При объединении файлов использован двоичный режим, сохраняющий все байты исходных данных.
