# Установка Mathcad для завершения лабораторных

Проверено 26 октября 2026 года. На компьютере Windows 11 x64; установленный Mathcad не найден.

Официальная загрузка: https://www.ptc.com/en/products/mathcad/free-trial

PTC предлагает Mathcad Prime с полными возможностями на 30 дней. Упрощённый Express не включает все возможности решения систем, требуемые для этих лабораторных. Сравнение редакций: https://www.ptc.com/en/products/mathcad/

Форма загрузки требует имя, фамилию, email, страну, телефон, организацию, род занятий и согласие с лицензионным соглашением. Форму пользователь заполняет самостоятельно. Контактные данные не вводились, согласие не принималось, установщик пока не скачан и программа не установлена.

Для актуальной версии Prime на официальной странице указан Microsoft .NET Desktop Runtime 10.0.x для Windows x64. При проверке обнаружены Desktop Runtime 8 и 9, но не 10. Ссылка производителя на требуемый компонент: https://dotnet.microsoft.com/en-us/download/dotnet/10.0

Методичка описывает классический Mathcad. Prime создаёт файлы .mcdx; официальное средство миграции переводит старые .mcd/.xmcd в Prime. Приём преподавателем файлов Prime пока не подтверждён. Описание форматов и конвертера: https://www.ptc.com/en/products/mathcad/migrate

Если кафедра выдаёт учебный установщик для своей версии, предпочтительно использовать его для совпадения с учебной виртуальной машиной. После получения подходящего установщика остаются установка, активация доступной лицензии и создание двух рабочих листов по уже подготовленным решениям.
