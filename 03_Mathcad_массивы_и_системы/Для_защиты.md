# Подготовка к защите Mathcad 2

Расчёты и графики подготовлены и независимо проверены в Python. Рабочий файл Mathcad и проверка внутри Mathcad пока отсутствуют.

Используй отчёт как порядок заполнения рабочего листа. В матричной формуле требуется обычное матричное умножение; оператор векторизации здесь не нужен. ORIGIN задаёт начальный индекс и не меняет математическую позицию элемента.

Важно для защиты: det(C) = 4, обратная C существует. Однако матрица M из третьего задания другая: det(M) = 0, ранг 2. Общее решение (t; 3−t; 3), а не «решений нет». Нельзя подменять исходную систему другой ради успешного вычисления M⁻¹ или lsolve.

Нелинейная система имеет касание в (e;1). Функция x/e−ln(x) не меняет знак, поэтому бисекция по смене знака для неё не подходит. Для кубического уравнения в задании 2 бисекция на [−2;−1] подходит: на концах разные знаки.

## Контрольные вопросы из методички

**1. Какие переменные называются ранжированными и как описываются?** Они задают последовательность значений аргумента: t:=начало, следующее значение .. конец. Например, t:=0,0.5..2 даёт шаг 0,5. Это диапазон перебора, а не обычный вектор с доступом по индексам.

**2. Как решают системы линейных уравнений?** В матричной форме M·X=b: при невырожденной M можно вычислить X=M⁻¹·b либо использовать lsolve(M,b). На практике lsolve предпочтительнее явного обращения. Для вырожденной матрицы исследуют ранги: решений может не быть или их может быть бесконечно много. В нашем варианте второе.

**3. Как решают нелинейные уравнения?** Формируют функцию невязки f(x), изучают область определения и график, выбирают начальное приближение или интервал, используют root и проверяют подстановкой. Корней может быть несколько, поэтому один запуск не доказывает единственность.

**4. Как устроен блок Given и зачем он нужен?** Сначала задают начальные приближения. После Given записывают уравнения и ограничения с булевыми знаками равенства; блок завершается Find или Minerr. Он задаёт систему условий для численного решения.

**5. Чем отличаются Find и Minerr?** Find ищет решение, удовлетворяющее условиям с нужной точностью. Minerr минимизирует невязки и может дать приближение даже тогда, когда точное согласованное решение не найдено. Результат Minerr обязательно проверяют по всем исходным уравнениям.

**6. Как задать массив без шаблона?** Определить индексированные элементы по формуле с диапазоном индексов, например i:=0..3 и vᵢ:=i². Для двумерного массива задают два индекса: Mᵢ,ⱼ:=выражение. Ввод индекса массива и буквенного нижнего индекса — разные операции.

**7. Что определяет ORIGIN?** Начальный индекс элементов массивов. При ORIGIN=0 первая строка имеет индекс 0; при ORIGIN=1 — индекс 1. Индексы должны быть целыми и лежать в допустимом диапазоне. Настройка не меняет размер матрицы.

**8. Что определяет TOL?** Рабочую точность, используемую рядом численных алгоритмов. Для ограничений решающих блоков в классических версиях также существенна CTOL. Конкретный алгоритм и его критерий остановки нужно учитывать; количество показанных знаков — отдельная настройка.

## Дополнительные вопросы по варианту 6

**Что означает C⁻¹?** Обратную матрицу, а не поэлементное 1/C. C·C⁻¹=I. В выбранном примере C диагональная, поэтому обратная состоит из обратных диагональных элементов.

**Где максимум матричного выражения?** max(A)=19 в третьей строке, третьем столбце. При ORIGIN=0 индекс (2,2).

**Что отвечать про ошибку при обращении матрицы системы?** det(M)=0, первые два столбца совпадают. Ранги M и [M|b] равны 2. Общее решение (t;3−t;3), t любое действительное. Нельзя утверждать «решений нет» по одному сообщению программы.

**Какой корень численного уравнения?** −1,930581179704456. Его невязка при полном вычислении близка к 7·10⁻¹⁵; в отчёте показана точность выше требуемой 10⁻⁴.

**Почему нелинейная система имеет только одно решение?** Разность x/e−ln(x) достигает единственного минимума 0 при x=e. Поэтому кривые касаются в (e;1).
